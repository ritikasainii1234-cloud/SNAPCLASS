# 📸 SnapClass — Smart Attendance System

An AI-powered attendance management system that marks student attendance using **Face Recognition** and **Voice Recognition** — built with Python, Streamlit, and Flask.

## 🚀 Features

- 🎭 **Face Recognition** — Auto-detect and mark attendance via camera
- 🎙️ **Voice Recognition** — Attendance via voice verification
- 📊 **Streamlit Dashboard** — Real-time attendance reports
- 🌐 **Flask Web Interface** — Easy-to-use web portal
- 💾 **Supabase Integration** — Cloud database for storing records
- 📱 **QR Code Generation** — Quick student identification
- 🔐 **Secure Login** — bcrypt password hashing

## 🛠️ Tech Stack

| Category | Technologies |
|----------|-------------|
| Frontend | Streamlit, Flask |
| AI/ML | Face Recognition, Resemblyzer, Librosa |
| Database | Supabase |
| Libraries | NumPy, Pandas, Scikit-learn, Pillow, Dlib |

## ⚙️ Installation

```bash
git clone https://github.com/ritikasainii1234-cloud/SNAPCLASS-MAIIN.git
cd SNAPCLASS-MAIIN
pip install -r requirements.txt
```

## ▶️ Run

```bash
# Streamlit Dashboard
streamlit run app.py

# Flask Web App
python app.py
```
